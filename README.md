# 拾光手记

按《手绘日记本网页版 PRD》实现的纯前端日记工具。无需登录，照片与文字保存在当前浏览器，不发送服务器。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
git clone https://github.com/Sky-Zxc/shiguang-diary.git
cd shiguang-diary
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。请固定使用同一地址、端口和浏览器访问，浏览器按站点来源隔离草稿。

## 手机通过局域网打开

开发服务与生产预览默认监听局域网接口。手机与这台电脑连接同一 Wi-Fi，电脑保持运行 `npm run dev`，即可在手机浏览器输入终端显示的 `Network` 地址。

例如电脑的局域网 IP 为 `192.168.1.100`，手机打开 `http://192.168.1.100:5173/`。实际地址以启动服务时打印的 `Network` 地址为准。电脑端仍可使用 `http://127.0.0.1:5173/` 访问原草稿。

手机支持新建和完整编辑，通过顶部“内容 / 预览 / 装饰”切换面板：上传照片、修改文字、切换样式和贴纸，在预览中点选照片并拖动边角调整背景大小；支持自动保存、页面管理和 PNG/PDF 导出。

草稿属于当前设备、浏览器及网站地址。电脑草稿不会随局域网访问自动同步到手机，同一电脑改用 IP 地址也不会自动迁移 `127.0.0.1` 下的旧草稿。查看电脑制作的日记可传输已导出的 PNG/PDF；本项目不增加云同步或草稿导入。

生产预览执行 `npm run build` 后运行 `npm run preview`，同一网络可使用该电脑 IP 加 `4173` 端口打开。离开同一局域网时需另行部署静态网站，本次不进行公网发布。

局域网 HTTP 地址不是安全上下文；应用使用 `crypto.getRandomValues` 兼容生成 ID，不依赖仅限安全上下文的 `crypto.randomUUID`。


```sh
npm run build     # 类型检查与生产构建，产物位于 dist/
npm run preview   # 预览生产构建，使用 4173 端口；草稿与 5173 端口隔离
npm test          # 数据模型、事务、共享图片引用、并发版本冲突测试
npx playwright install chromium
npm run test:e2e  # 浏览器编辑、持久化、下载、错误恢复与响应式测试
npx playwright install webkit
npm run test:browsers # 同时验证 Chromium 与 WebKit
```

部署时将 `dist/` 放到静态 Web 服务器；无后端或密钥要求。请通过 HTTP/HTTPS 运行，不能直接双击 `index.html`。

## 已实现

- 首页、历史记录合并展示，按修改时间排序；新建、继续编辑、直接导出 PDF、二次确认删除。
- 三栏实时编辑器；每本 1–3 页，添加、切换、复制、删除；每页独立内容和样式。
- 点击及拖入 JPG/PNG/WebP，本地校验和压缩至长边不超过 1600px；每页最多 6 张，支持替换、删除、拖拽排序和键盘按钮排序。
- 五种拼贴风格，白边、圆角、阴影相框；自动相框贴合照片原比例，单张照片时按正文长度分配照片空间，保留完整照片。选中照片后可拖动外框四边及四角调整整块背景的宽高，支持方向键微调、Shift 加速、Escape 取消当前拖动和一键恢复自动背景大小。
- 日记本标题、页面标题、正文、日期、心情、天气、地点；正文计数及溢出版式提示。
- 五种纸张、三种边框、两款本地开源中文手写字体、六种文字颜色、三档字号。
- 五种手绘贴纸，添加、选择、删除、画布内自由拖动、方向键微调、预设位置及随机位置；支持经确认将当前页样式应用到其他页。
- IndexedDB 分开存储草稿与图片 Blob，900ms 防抖自动保存、手动保存、离开保存、保存失败重试和未保存离开提示。
- 复制页复用不可变图片 Blob，页面数据独立；无引用图片自动回收。元数据和图片原子写入，版本检测避免多标签页静默覆盖。
- 共用 Canvas 渲染器，预览、PNG、PDF 使用同一绘制路径；等待每个待导出页的字体和图片，支持逐页进度、错误重试、下载恢复。
- 当前页 PNG 为 1600×2000px；PDF 每页 160×200mm，按顺序保留 4:5 比例。
- 768–1199px 装饰抽屉与内容上下布局；小于 768px 使用内容、预览、装饰三个触屏面板，支持完整编辑、保存及导出。
- 原生可访问弹窗、键盘操作、焦点样式、加载、空状态、错误提示和减少动画偏好。

## 本次采用的产品默认值

这些默认值使原文待确认项可以实际运行，后续可按产品决策调整。

| 待确认点 | 当前实现 |
|---|---|
| 应用到其他页的 MVP 范围 | 已实现；只覆盖纸张、边框、字体、字色和字号，不复制照片、正文、布局或贴纸 |
| 页序 | 添加至末尾，副本插入原页后；删除选中页后优先选择前一页 |
| 空白页 | 可保存、可导出；导出移除照片和正文的编辑引导，保留日期、心情/天气及纸张装饰 |
| 1–6 张照片与固定布局 | 按照片数量自动适配，所有照片完整显示；自动相框按照片原比例收合；单张照片且正文较少时利用可用空间放大照片；五种选择分别控制拍立得留白、并排、错落、网格和胶带效果 |
| 默认模板 | 米白、波浪边、山野手记、暖墨棕、16 档；新建页使用默认值，复制页使用原页值 |
| 正文字数 | 500 字为建议，5000 字为输入保护上限；按 Unicode 码点计数；实际可见内容由版式、照片数量与字号决定 |
| 内容溢出 | 预览警告，阻止导出，提示具体页码；用户需缩小字号或精简文字，避免不知情截断 |
| 标题与地点 | 日记本和页面标题各 30 个 UTF-16 单位；地点 40 个单位；空日记本标题显示“未命名日记本” |
| 心情与天气 | 两个独立可选字段，均可不显示；日期按新建时本地日期初始化，之后保持原值 |
| 文字样式入口 | 统一在右栏；正文使用所选字号档，标题和元信息按固定比例搭配，颜色和字体作用于整页文本 |
| 贴纸 | 最多 8 个，允许重复类型；8 个预设位置及自由位置，选中画布中的贴纸可拖动；支持方向键与 Shift 微调，Escape 取消当前拖动，位置自动保存并用于 PNG/PDF；随机操作会重置自由位置；可覆盖内容，需自行选择合适位置 |
| 照片压缩 | 10MB = 10×1024×1024 字节；浏览器解码校正方向后以 WebP 0.88 压缩并保留透明度，动态图取解码静态帧 |
| 照片背景手动大小 | 外框四边分别调整宽高，四角同时调整；按旋转后的外框限制边界与最小尺寸，保持对侧边角固定。照片按比例完整显示，正文跟随照片区域底部重新排布，结果自动保存并用于导出；替换照片保留尺寸，更换排版、增删或重新排序照片时恢复自动排版 |
| 图片清晰度 | 不放大原始小图；高清导出不保证小尺寸源图具有新增细节 |
| 文件名日期 | 使用用户本地导出当天日期，PNG 页码使用当前页序号 |
| 保存失败与导出 | 保存失败保留内存内容，仍可尝试导出；离开失败草稿需再次确认 |
| 多标签页编辑 | 保存检查持久化版本，冲突时拒绝覆盖；可先导出本页修改，再重新打开最新草稿 |
| 手机编辑 | 可新建、上传、编辑、装饰、拖动照片背景、管理页面及导出；草稿仅存于当前设备和浏览器，无云同步或导入功能 |
| 容量 | 不限制日记本数量；实际可用容量由浏览器配额决定，满额时明确报错且不删除旧草稿，不能保证所有浏览器均容纳 180 张照片 |
| 刷新保障 | 已保存草稿可恢复，防抖期间会显示待保存状态；未保存刷新/关闭时使用浏览器离开确认，不能保证强制退出前的异步写入 |
| 下载完成 | 文件生成后发起下载；无法确认磁盘最终写入，保留“再次下载”入口 |

## 实现结构

- `src/model.ts`：页面边界、默认值、复制和应用样式。
- `src/db.ts`：IndexedDB 事务、版本检查、图片引用回收。
- `src/useDiary.ts`：保存队列、编辑版本及离开保护。
- `src/resources.ts`：图片校验、压缩、缓存和字体就绪检查。
- `src/photoGeometry.ts`：照片背景尺寸、旋转坐标换算及拖拽边界。
- `src/stickerGeometry.ts`：贴纸预设与自由位置、旋转边界限制。
- `src/renderer.ts`：固定 800×1000 逻辑画布、排版、贴纸绘制与选中命中区域。
- `src/exporter.ts`：2x PNG 和 PDF 生成，PDF 库按需加载。
- `src/Home.tsx` / `src/Editor.tsx`：首页与编辑器。
- `tests/`：核心数据和浏览器测试；`artifacts/`：本地生成的验收截图与示例导出（不纳入 Git）。

## 数据与隐私

存储库为 `shiguang-diary`，`diaries` 保存结构化日记与封面缩略图，`images` 保存独立图片二进制及 MIME 类型，读取时还原为 Blob。采用 ArrayBuffer 持久化以兼容 WebKit 对 Blob 后备文件写入的限制，同时可读取旧 Blob 记录。清除站点数据会永久移除草稿，PNG/PDF 导出文件不能重新导入为可编辑草稿。项目没有埋点、上传接口、远程字体或第三方运行时图片请求。
